# Solution

## Overview

The implemented logic parses HTML documents to extract the "carousel" nodes and returns a standarized response format with the content of the elements.

The implementation has been tested with three different documents, with different categories (artworks, books and music) to validate the implementation is generic enough to support multiple "search" pages documents.

## Architecture

![Architecture Diagram](diagrams/architecture.png)


### Core Components

1. **Scrapper** (`lib/scrapper.rb`) - Main entry point that orchestrates the extraction process
2. **Search Document Parser** (`lib/search_documents/`) - Handles HTML parsing logic for different search engines
3. **Extraction Service** (`lib/services/carousel_extraction_service.rb`) - Business logic for extracting carousel data
4. **Data Transfer Objects** (`lib/dtos/`) - Structured data representations
5. **Formatters** (`lib/formatters/`) - Output formatting (currently supports JSON)

### Design Patterns

- **Strategy Pattern**: Different search engines can be supported through the `SearchDocuments::Base` interface
- **Template Method**: Formatters follow a consistent interface through `Formatters::Base`
- **Factory Pattern**: The `Scrapper` class selects appropriate formatters and extraction services

## How It Works

### 1. HTML Parsing (`lib/search_documents/google.rb`)

The solution identifies Google's knowledge carousel by looking for elements with the `data-attrid` attribute starting with "kc:":

```ruby
def kc_node
  @kc_node ||= at_css('[data-attrid^="kc:"]')
end
```

It extracts:
- **Carousel title**: Found in heading elements with `aria-level="2"` and `role="heading"`
- **Item nodes**: Links containing `href*="search?"` within the carousel

Note: It was quite challenging to correctly parse each item since in the different documents, the structure was not the same. We always start from the anchor tag with the mentioned href attribute, but sometimes the name and extension can be found nested in that anchor tag, other times it's a "sibbling".

### 2. Data Extraction (`lib/services/carousel_extraction_service.rb`)

For each item, the service extracts:

- **Name and Date**: Parsed from child div elements, taking the last two text values
- **Google Link**: Constructs full URLs from relative href attributes
- **Thumbnail Images**: Handles multiple image sources:
  - `data-src` attributes (lazy-loaded images)
  - Standard `src` attributes
  - Deferred images via JavaScript lookup (base64 encoded)

### 3. Image Handling

To find the image, the logic first finds the img tag. If it has a `data-src` attribute, then we just use that. Otherwise we check if the `data-deferred` attribute is present. When it has `data-deferred`, we must find a `<script>` tag that sets the base64 image using the tag id.

```ruby
def image_from_item(item)
  # Sometimes the img tag and the anchor tag share the same parent, sometimes they don't.
  img = item.at_css('img') || item.parent.at_css('img')
  return unless img

  return img['data-src'] unless img['data-src'].nil?
  return if (img_src = img['src']).nil?

  # Handle deferred images
  return find_image_from_script(img['id']) if img['data-deferred'] == '1'

  img_src
end
```

### 4. Output Format

The app has a "Base" formatter that acts as an interface and makes extending the supported formats easy.
To add a new response format (e.g. xml, or simple another JSON structure) we just need to implement the `parse` method and we can use a `DTOs::Carousel` object instance to build our response.

The `JsonFormatter` class returns a structure matching the `files/expected_array.json` format:

```json
{
  "artworks": [
    {
      "name": "The Starry Night",
      "extensions": ["1889"],
      "link": "https://www.google.com/search?...",
      "image": "data:image/jpeg;base64,..."
    }
  ]
}
```

## Usage

```ruby
# Basic usage
scrapper = Scrapper.new(file_path: 'path/to/html/file')
result = scrapper.scrap

# With different engine (extensible)
scrapper = Scrapper.new(
  file_path: 'path/to/html/file', 
  engine: 'google',
  format: 'json'
)
```
